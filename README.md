# 🎨 ARTOVA — AI Image Generator

ARTOVA is a **full-stack AI image generation platform** powered by the **ClipDrop API**, built using the **MERN stack** with secure authentication, JWT-based user sessions, credit-based image generation, and a modern UI with smooth animations.

---

## 🚀 Live Features

✔ User Authentication (Signup / Login)  
✔ JWT-based Secure Authorization  
✔ Credit System (5 Free Credits per User)  
✔ ClipDrop AI Image Generation  
✔ Auto-Debit Credits After Generation  
✔ Fully Responsive UI  
✔ Toast Notifications  
✔ Protected Routes  
✔ Modern Motion Animations  
✔ Integrated Frontend + Backend

---
